# Support

Before opening an issue:

1. Confirm the operating system, Illustrator version, MyVibe version, and plug-in version are supported by `catalog.json`.
2. Close Illustrator and retry the operation.
3. Include the exact error message and whether the installation is new, updated, or restored.
4. Do not attach private artwork, credentials, `.env` files, signing certificates, or AI chat exports.

Use GitHub Issues for reproducible bugs and feature requests. Use private vulnerability reporting for security concerns.
